# LavaNames

Плагин для Paper и Purpur 1.21.4, Java 21. Показывает префикс, ник и статистику над игроком и скрывает ванильный никнейм.

[Скачать LavaNames](https://github.com/svarcovv/LavaNames/releases/download/v1.0.0/LavaNames-1.0.0.jar)

По факту плагин является бесплатной версией плагина ElyBoxNames но исправленной.
В плагине ElyBoxNames (Слитая версия 1.4.1) были некоторые баги которые я исправил в LavaNames а именно:

1. Была добавлена неплохая оптимизация которой не хватало в слитой версии (При 50 игроках в 1 месте это неплохо заметно)
2. Больше нет фантомных голограмм которые просто зависли в воздухе. 
3. Исправил отображение хп над головой (Были баги что отображалось оно примерно так: 12.1020200)

## Команды

- `/lavanames reload` - перезагрузить конфиг.
- `/lavanames refresh` - обновить голограммы.
- `/lavanames status` - показать состояние плагина.

Сокращение команды - `/lnames`.

## Настройки

Текст, масштаб, высота, дальность и отдельные строки настраиваются в `config.yml`. Сообщения - в `messages.yml`.

Ник, здоровье, убийства и смерти работают без расширений PlaceholderAPI. Префиксы и суффиксы берутся из LuckPerms.
