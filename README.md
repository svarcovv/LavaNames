# LavaNames

Плагин для Paper и Purpur 1.21.4, Java 21. Показывает префикс, ник и статистику над игроком и скрывает ванильный никнейм.

[Скачать LavaNames 1.0.0](https://github.com/svarcovv/LavaNames/releases/download/v1.0.0/LavaNames-1.0.0.jar)

- Голограммы следуют за игроком при беге и полёте.
- Удаляются при выходе, смерти, смене мира и потере видимости.
- Скрываются в режиме наблюдателя, при невидимости и приседании.
- Поддерживают PlaceholderAPI, префиксы LuckPerms, MiniMessage и цветовые коды `&`.
- Сохраняют команды, префиксы и правила столкновений TAB.

## Команды

- `/lavanames reload` - перечитать настройки.
- `/lavanames refresh` - обновить голограммы.
- `/lavanames status` - показать состояние плагина.

Право `lavanames.admin` доступно операторам. Сокращение команды - `/lnames`.

## Настройки

Текст, масштаб, высота, дальность и отдельные строки настраиваются в `config.yml`. Сообщения - в `messages.yml`.

Ник, здоровье, убийства и смерти работают без расширений PlaceholderAPI. Префиксы и суффиксы берутся из LuckPerms.
